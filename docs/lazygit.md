# lazygit

Конфиг: `lazygit/config.yml` (`~/.config/lazygit/config.yml`). Версия: 0.66.2.

Запуск: `lazygit` в репозитории или `<leader>lg` в nvim (плагин `kdheepak/lazygit.nvim`).
Справка по клавишам для текущей панели: `?`. Выход: `q`.

## Что настроено

- Тема в цветах Tokyo Night, Nerd Font иконки (`nerdFontsVersion: "3"`), язык интерфейса `en`.
- Диффы рендерит `delta` (`brew install git-delta`).
- Файлы открываются в `nvim` (`os.edit`).

## Панели

Переключение: `1`..`5` или `[` / `]`, а `<tab>` меняет основную/дополнительную панель.

1. Status 2. Files 3. Branches 4. Commits 5. Stash

## Основные клавиши

| Клавиши | Действие |
|---|---|
| `space` | добавить/убрать файл из индекса |
| `a` | добавить/убрать все файлы |
| `c` | коммит |
| `A` | дополнить последний коммит (amend) |
| `P` | push |
| `p` | pull |
| `f` | fetch |
| `n` | новая ветка / новый элемент |
| `space` (в ветках) | checkout |
| `d` | удалить / сбросить изменения (с подтверждением) |
| `e` | открыть файл в nvim |
| `o` | открыть файл системной программой |
| `s` (в Files) | stash |
| `m` | меню rebase/merge |
| `z` / `Z` | отменить / повторить действие (reflog) |
| `+` / `_` | увеличить / уменьшить режим экрана |
| `ctrl+s` | фильтр по пути |
| `ctrl+r` | недавние репозитории |
| `enter` | зайти внутрь (файл -> hunks, коммит -> файлы) |
| `<esc>` | назад |
| `/` | поиск в списке |

Фактические клавиши зависят от версии: `lazygit -c` печатает дефолтный конфиг с `keybinding:`, а в самом приложении `?` показывает меню текущего контекста.

## Типовой сценарий

1. `lazygit`, в панели Files `space` на нужных файлах (или `a` на все).
2. `c`, написать сообщение, `enter`.
3. `P` для push.

Построчный/hunk-staging: `enter` на файле, `space` на строке, `a` на hunk.

## Конфиг

```yaml
gui:    # тема, иконки
git:    # diffRenderers: delta
os:     # edit: nvim
```

`lazygit/state.yml` (история, недавние репозитории) в git не попадает.

# tmux

Конфиг: `tmux/tmux.conf` (symlink на `~/.tmux.conf`). Версия: tmux 3.8.

**Префикс: `Ctrl+a`** (вместо `Ctrl+b`). Ниже «prefix» значит: нажать `Ctrl+a`, отпустить, нажать клавишу.
Дважды `Ctrl+a` отправляет `Ctrl+a` в программу внутри (например, в shell).

## Сессии, окна, панели

| Клавиши | Действие |
|---|---|
| `prefix` `c` | новое окно в текущей директории |
| `prefix` `\|` | вертикальный сплит (панели рядом), путь сохраняется |
| `prefix` `-` | горизонтальный сплит (панели друг под другом), путь сохраняется |
| `prefix` `m` | развернуть панель на весь экран / вернуть обратно |
| `prefix` `h` `j` `k` `l` | ресайз панели на 5 клеток; можно нажимать подряд (repeat) |
| `prefix` `s` | дерево сессий, отсортированное по имени |
| `prefix` `r` | перезагрузить конфиг |
| `prefix` `d` | отключиться от сессии (сессия продолжает жить) |
| `prefix` `,` | переименовать окно |
| `prefix` `1`..`9` | перейти в окно по номеру (нумерация с 1, панели тоже с 1) |
| `prefix` `x` | закрыть панель |

Мышь включена: клик выбирает панель, перетаскивание границы меняет размер, колесо скроллит.

Из консоли:

```sh
tmux new -s work          # новая сессия
tmux ls                   # список сессий
tmux attach -t work       # подключиться
tmux kill-session -t work # убить сессию
```

## Режим копирования (vi)

`prefix` `[` входит в copy-mode. Навигация как в vim (`h j k l`, `/` поиск, `gg`/`G`).

| Клавиши | Действие |
|---|---|
| `v` | начать выделение |
| `y` | скопировать выделение |
| `q` | выйти |

Выделение мышью не сбрасывается при отпускании кнопки.

## Плагины (TPM)

Менеджер: `~/.tmux/plugins/tpm`. После клонирования репозитория нажми `prefix` `I` (заглавная i) для установки, `prefix` `U` для обновления, `prefix` `alt+u` для удаления лишних.

| Плагин | Что даёт |
|---|---|
| `tmux-sensible` | разумные настройки по умолчанию |
| `vim-tmux-navigator` | `Ctrl+h/j/k/l` переключает между панелями tmux и окнами nvim без префикса (нужен парный плагин в nvim) |
| `tmux-themepack` | тема `powerline/default/cyan` |
| `tmux-sessionist` | `prefix` `g` перейти в сессию по имени, `prefix` `C` создать сессию, `prefix` `X` убить сессию, `prefix` `S` переключиться на последнюю сессию |
| `tmux-resurrect` | сохранение/восстановление сессий: `prefix` `Ctrl+s` сохранить, `prefix` `Ctrl+r` восстановить; содержимое панелей сохраняется |
| `tmux-continuum` | автовосстановление последнего сохранения при старте tmux |

### Как работает сохранение сессий

- Автосохранение выключено (`@continuum-save-interval '0'`), чтобы удалённые сессии не воскресали. Сохраняй вручную: `prefix` `Ctrl+s`.
- При запуске tmux последнее сохранение восстанавливается само (`@continuum-restore 'on'`).
- `destroy-unattached off` держит сервер живым, пока в нём есть сессии.

## Если что-то не работает

- Нет иконок/цветов: проверь, что в терминале включён Nerd Font; в конфиге `default-terminal "screen-256color"`.
- Плагины не загрузились: `prefix` `I`, затем `prefix` `r`. Проверь, что есть `~/.tmux/plugins/tpm`.
- `Ctrl+h/j/k/l` не работают внутри nvim: нужен плагин `christoomey/vim-tmux-navigator` на стороне nvim.

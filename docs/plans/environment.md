отдельное удаление для переустановки. Bash 3.2+, Python 3 для загрузки релизов.

Решения: сервер использует apt и минимальный Neovim без плагинов. Утилиты,
которых нет в apt, загружаются локально из официальных GitHub Releases с проверкой
SHA256 из API. Системная login shell и настройки SSH не меняются.
Удаление пакетов запрашивается отдельно; зависимости не удаляются принудительно.

Риски проверки: на этой машине нет CachyOS/Ubuntu VM; пакетные менеджеры Linux
проверяются через перехват команд, а не настоящую установку. Существующие кеши и
SDKMAN принадлежат пользователю, их удаление возможно только отдельными флагами.

Проверка: 13 изолированных тестов, Bash/zsh/Lua/Ruby/Nu syntax checks.
Независимый review: замечание о старых Neovim исправлено совместимыми vim.o и
nvim_set_keymap. Linux пакетные операции проверены подставными backend-командами.
